数据类型和变量

Python 中的数据类型包括整数、浮点数、字符串与布尔值等。变量在赋值时创建， 不需要预先声明类型，解释器会根据赋值自动推断变量的类型。

整数

Python 可以处理任意大小的整数，包括负整数。十六进制整数使用 0x 前缀表示， 数字之间允许使用下划线分隔，便于阅读较长的数值。

浮点数

浮点数即小数，可以用数学写法表示，也可以用科学计数法表示。 由于计算机内部采用二进制存储，浮点运算可能存在四舍五入的误差。

字符串

字符串可以用单引号或双引号括起来。如果字符串本身包含引号， 可以换用另一种引号，或者使用反斜杠进行转义。

转义字符与原始字符串

常见的转义字符包括换行符、制表符与反斜杠本身。 在引号前加字母 r 表示原始字符串，其中的字符不再转义。

除法运算

斜杠除法得到浮点数结果，即使两个整数整除，结果也是浮点数。 双斜杠是地板除，两个整数相除的结果仍然是整数。

布尔值

布尔值只有真与假两个取值，通常由比较运算产生，并广泛用于条件判断与循环控制。 布尔值可以与整数进行运算转换，真等价于一，假等价于零。

变量与赋值

变量名由字母、数字与下划线组成，且不能以数字开头。 同一个变量可以先后指向不同类型的数据，这种特性称为动态类型。
